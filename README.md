# D&D Campaign Companion

Final project: a vanilla HTML/CSS/JS app for dungeon masters.

## Run it
ES modules need a web server (opening index.html directly will not work).
Use VS Code's Live Server extension, or run `npx serve` in this folder.

## Lint
```
npm install
npm run lint
```
